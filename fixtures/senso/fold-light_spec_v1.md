## Overview
The Fold task light (fold-light) is a compact metal task light that folds flat for storage.

## Light source
The Fold task light uses an LED light module built into the head.

## Repair & parts
The Fold task light LED module is integrated and is not user-replaceable.

If the light module fails, the whole fixture is replaced under warranty. No replacement modules are sold.

## Warranty
The Fold task light has a one-year fixture warranty. A failed light module is handled by replacing the whole fixture.
